# FIRST CONTACT

`HELLO:// NEIGHBOR_01` is a physical-digital first-contact protocol. OBJECT 001 is intended to open this mobile-first experience through NFC, with QR as a fallback.

This repository is not a disposable prototype. The current implementation establishes the production frontend foundation: the visual system, interactive 3D world, deterministic narrative state, NODE O exploration, source reveal, mobile constraints, accessibility motion fallback, and CI build gate.

## Current journey

1. OBJECT 001 boot
2. Context establishment
3. Two neighboring structures appear
4. `PROXIMITY HIGH / INTRODUCTIONS 0`
5. Design-problem reveal
6. Interactive NODE O
7. Four fragments: BUILD / SOUND / OBJECT / DOOR

The next production slice adds recipient identification, explicit connection consent, bridge construction, response channel, signed encounter tokens, and persistent backend delivery.

```bash

```

## Product rules

- No covert location/device/contact collection.
- No real apartment/floor reconstruction.
- Recipient controls whether a connection proceeds.
- `ARCHIVE` must end an encounter without nudges or retries.
- Physical object and digital world are one product, not a QR landing page.
